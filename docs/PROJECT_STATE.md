# אוצר ישראל — מצב פרויקט

## מטרה
מאגר יהודי אחוד שמרכז טקסטים תורניים, תפילות וכתבים, עם חיפוש, קריאה וקשרים בין מקורות.

## ארכיטקטורה
- Frontend: React + TypeScript + Vite, RTL מלא.
- Backend: FastAPI + SQLAlchemy.
- Database: PostgreSQL ב-Railway, SQLite לפיתוח מקומי.
- מקור יבוא ראשון: Sefaria Export / API.

## כללי ליבה
1. אין לייבא אוטומטית מהדורה ללא רישיון מפורש.
2. כל גרסת טקסט נשמרת עם source_url, source_name, license ו-license_verified.
3. טקסטים עם NC לא נכנסים אוטומטית כדי לשמור אפשרות עתידית לשימוש מסחרי.
4. טקסטי המקור נשמרים מקומית במסד הנתונים; האתר אינו תלוי בזמינות Sefaria בזמן קריאה.
5. החיפוש מבצע נרמול עברי בסיסי ומסיר ניקוד וטעמים.
6. המבנה מתוכנן להתרחב לקישורים בין מקורות, תפילות לפי נוסח, משתמשים ומועדפים.

## מצב 0.1.0
- שלד frontend/backend קיים.
- מסך בית, ספרייה, מסך קריאה וחיפוש קיימים.
- API לספרים, קטגוריות, קטעים וחיפוש קיים.
- Sefaria importer ראשוני קיים עם שער רישוי.
- Docker ו-Railway configs קיימים.
- טרם בוצע יבוא corpus מלא.
- טרם הוגדרו Alembic migrations מלאות; בשלב זה הטבלאות נוצרות באתחול.
