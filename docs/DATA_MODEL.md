# מודל הנתונים

## Work
היצירה הלוגית: בראשית, ברכות, משנה תורה וכו'.

## TextVersion
מהדורה מסוימת של היצירה. הרישיון משויך למהדורה ולא ל-Work כולו.

## TextSegment
יחידת הטקסט הקטנה לצורך קריאה וחיפוש. נשמר ref אנושי, מיקום היררכי וטקסט מנורמל.

## עקרון זכויות
המערכת מציגה אוטומטית רק TextVersion עם license_verified=true.
